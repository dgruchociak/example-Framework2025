# Example Framework 2025

This project is a C# framework for:
- integration testing using WireMock.NET and the Coinpaprika API.
- ui testing using Selenium
- contract testing / unit testing / e2e testing TBD

## Project Structure

- `Core/`: Contains core functionality and helpers
- `Tests/`: Contains tests
- `WiremockServer/`: Contains WireMock server setup and configuration

## Setup and Usage

1. Clone the repository
2. Open the solution in Visual Studio/Rider
3. Restore NuGet packages
4. Build the solution
5. Run tests using the Test Explorer

## Dependencies

- WireMock.NET
- NUnit
- RestSharp
- Newtonsoft.Json
- Selenium
